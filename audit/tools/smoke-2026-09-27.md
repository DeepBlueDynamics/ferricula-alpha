## What this found and fixed
1. A model that is not pushed to use tools answers from its own sense of the document. Fix: tools block first in the system prompt, and an explicit rule never to claim reading or quote anything not shown this turn.
2. A deterministic guard catches fabricated reading: citing a document not shown this turn gets one correction round (`citation_check`).
3. Ollama with GLM parses `<tool_call>` itself. The protocol tag is now `<use_tool>`; `<tool_call>` is still accepted, and structured `tool_calls` are turned back into text blocks.
4. Empty thinking-model replies: one retry with double the reasoning headroom; one nudge mid-loop.
